# Steam Recommender System

## How to run:

** Dataset and libraries are extrememly large so a storage size of about 30GB is requried **

## Backend:
```console
cd Back-End/Methods/ 
python -m venv venv
```

**For a specific version you can also do** 
```console
py -3.xx -m venv venv
```


**Install Libraries**  
```console
pip install -r requirements.txt
```

**Then Run server** 
```console
py server.py
```


## Frontend:
Open a new second terminal

```console
cd Front-End/
npm install
```

(If theres an error because of a missing package.json you might need to request it from one of the members)
```console
npm start
```
